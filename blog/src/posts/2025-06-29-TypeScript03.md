## 타입 별칭(Type Alias)

특정 타입이나 인터페이스 등을 별도의 이름으로 부르는 것

특정 타입의 이름을 짓고 싶을 때, **여러번 반복되는 타입을 변수화**하고 싶을 때 사용

```tsx
type MyName = string;
var capt: MyName = "캡틴";

type MyMessage = string | number;
function logText(text: MyMessage) {
  // ...
}

var message: MyMessage = "안녕하세요";
logText(message);
```

타입 별칭과 인터페이스의 차이점?

- 인터페이스는 객체의 타입을 정의하는 데 사용
- 타입 별칭은 원시 타입, 유니언, 인터섹션 타입, 제네릭, 유틸리티 타입, 맵드타입에도 사용 가능

실무에서는 인터페이스와 타입 별칭을 섞어서 사용하고 보통 컨벤션으로 지정

타입 별칭으로만 타입 정의가 가능한 곳에서는 타입 별칭 사용을 권장

### 타입 확장에서 타입 별칭과 인터페이스의 차이

```tsx
// 인터페이스
interface Person {
  name: string;
  age: number;
}

interface Developer extends Person {
  skill: string;
}

var joo: Developer = {
  name: "형주",
  age: 21,
  skill: "웹개발",
};
```

```tsx
// 타입 별칭(인터섹션 타입 응용)
type Person = {
  name: string;
  age: number;
};

type Devloper = {
  skill: string;
};

var joo: Person & Developer = {
  name: "형주",
  age: 21,
  skill: "웹개발",
};
```

```tsx
// 타입 별칭 (인터섹션 타입을 타입 별칭으로 작성)
type Person = {
  name: string;
  age: number;
};

type Devloper = {
  skill: string;
};

type Joo = Person & Devloper;

var joo: Joo = {
  name: "형주",
  age: 21,
  skill: "웹개발",
};
```

## 이넘(enum)

특정 값의 집합을 의미하는 데이터 타입 = 상수 집합

이넘에 선언된 속성은 기본적으로 숫자 값을 가짐

```tsx
enum Direction {
  Up, // 0
  Down, // 1
  Left, // 2
  Right, // 3
}
```

자바스크립트로 컴파일해 보면 숫자 값을 가지는 이유를 알 수 있음

```tsx
// JS 컴파일 시 IIFE로 변환
var Direction;
(function (Direction) {
  Direction[(Direction["Up"] = 0)] = "Up";
  Direction[(Direction["Down"] = 1)] = "Down";
  Direction[(Direction["Left"] = 2)] = "Left";
  Direction[(Direction["Right"] = 3)] = "Right";
})(Direction || (Direction = {}));
```

`Direction[Direction["Up"] = 0] = "Up"` 이 한 줄이 두 가지 매핑을 동시에 만듦

1. `Direction["Up"] = 0` → 숫자 할당 후 `0`을 반환
2. `Direction[0] = "Up"` → 반환된 `0`을 키로 리버스 매핑(reverse mapping)

결과적으로 이런 식의 객체가 됨

```tsx
{
  Up: 0,
  Down: 1,
  Left: 2,
  Right: 3,
  0: "Up",
  1: "Down",
  2: "Left",
  3: "Right"
}
```

### 문자형 이넘 ⭐️

이넘의 속성 값에 문자열을 연결한 이넘

실무에서는 숫자형 이넘보다 문자형 이넘이 훨씬 많이 사용 된다

```tsx
enum Direction {
  Up = "Up",
  Down = "Down",
  Left = "Left",
  Right = "Right",
}

console.log(Direction.Up); // "Up"
```

### 다양한 이넘 속성값

문자와 숫자를 섞을 수도 있고, 고정값이 아닌 다양한 형태로도 할당할 수 있음

먼저 선언되어 있는 이넘의 속성을 활용할 수도 있고,

- 활용해서 계산한 값을 속성으로 할당할 수도 있음

```tsx
enum Answer {
  Yes = "Yes",
  No = 1,
}

enum Authorization {
  User, // 0
  Admin, // 1
  SuperAdmin = User + Admin, // 0 + 1 = 1
  God = "abc".length, // 3
}
```

### const enum

이넘을 선언할 때 앞에 const를 붙인 enum을 의미

const enum은 컴파일 시 객체를 따로 생성하지 않고 사용되는 곳에서 바로 속성 값을 연결

⇒ 컴파일 시 코드 양을 줄여주는 효과

하지만 고정 속성 값만 사용할 수 있음

```tsx
const enum loglevel {
  Debug = "Debug",
  Info = "Info",
  Error = "Error",
}
```

## 클래스

클래스 접근 제어자 private, public, protected 사용 가능

protected는 외부에서 사용 X 상속받은 클래스에서는 사용 O

생성자 매개변수에 접근 제어자를 직접 붙이면 변수 선언과 초기화를 한 번에 해결해 주는 단축 문법 제공

런타임에 강제로 접근하려면 접근할 수도 있음

```tsx
// 일반 형식
class Developer {
  private skill: string;

  constructor(skill: string) {
    this.skill = skill;
  }
}

// 단축 문법
class Developer {
  // 생성자 매개변수에 private을 붙이면 멤버 변수 선언과 자동 할당이 동시에 됨
  constructor(private skill: string) {}

  public coding() {
    console.log(`${this.skill}로 개발 중...`);
  }
}

const dev = new Developer("TypeScript");
dev.coding(); // TypeScript로 개발 중...
```
